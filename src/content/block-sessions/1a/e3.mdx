Command the MG90S rudder servo — center it, sweep it port↔starboard, and map a clean **−1…+1 steering value** to a physical angle, using LEDC (no servo library). You'll end with the servo horn sweeping smoothly left↔center↔right on a loop, wrapped in a `Steering` class with the same `set(-1..1)` shape as E2's `PaddleDrive`.

<KeyTerms terms={[
  { term: "Closed-loop position device", definition: "A hobby servo (motor + gearbox + potentiometer + control circuit inside) — you command a target angle, not a speed, and it holds itself there." },
  { term: "Pulse-width command", definition: "The command is a pulse repeated every ~20 ms (50 Hz); the width of the pulse encodes the angle — 1.0 ms ≈ full one way, 1.5 ms ≈ center, 2.0 ms ≈ full the other way, though real endpoints vary unit-to-unit (that's why you trim by eye)." },
  { term: "Mechanical stop", definition: "Never command past it — the servo will buzz, draw stall current, heat up, and can strip its gears. Start with a conservative range and only widen it after seeing where the real rudder hits its limits." },
  { term: "50 Hz / 16-bit LEDC", definition: "Generated at 50 Hz, 16-bit resolution (duty 0…65535). Converting a desired pulse width in microseconds to a duty value: duty = us × 65536 / 20000." },
]} />

<Section title="Wiring (given)" icon="🔌" id="wiring">

MG90S 3-wire lead straight into the **GPIO 25** servo header (orange → signal, red → 5V, brown → GND) — nothing to solder. **Leave the horn unscrewed from the rudder for this session** so a mis-trim can't jam anything.

Once you see the sweep: **fit the horn** so it points straight down the rudder line when the printed value passes through 0, screw it on, then check the ends — if it buzzes or hits a hard stop before `s = ±1`, **reduce `STEER_RANGE_US`** and re-test. <Support title="Hint 1 — the set() formula">
You want: at `s = -1`, output `STEER_CENTER_US - STEER_RANGE_US`; at `s = 0`, output `STEER_CENTER_US`; at `s = +1`, output `STEER_CENTER_US + STEER_RANGE_US`. That's a single linear expression — `center + s * range` — cast to an `int`.
</Support>

<Support title="Hint 2 — the duty conversion">
`(uint32_t)((uint64_t)us * (1UL << SERVO_BITS) / SERVO_PERIOD_US)` is the whole conversion — it's the `duty = us × 65536 / 20000` formula from the concepts section, written to avoid overflowing a 32-bit int mid-calculation.
</Support>

<Support title="Hint 3 — still stuck">
Ask: "what two things does `set()` need to do — turn `s` into a microsecond pulse width, then hand that off to something that already knows how to output a pulse width?" That second something is `writeMicroseconds`, which you're also filling in — so `set()` should end with a single call to it.
</Support>

<Section title="Troubleshooting" icon="🩹" id="troubleshooting">

Phase-specific traps — general tooling issues are in the <SessionLink code="troubleshooting">Troubleshooting — Common Issues</SessionLink> page.

- **Servo doesn't move at all:** jack not powered (5V rail dead), or signal on the wrong header pin.
- **Buzzing / hot / jitter at the ends:** commanding past the mechanical stop — lower `STEER_RANGE_US`.
- **Moves the wrong way:** flip the sign in `set()`, or rotate the horn 180° on the spline.
