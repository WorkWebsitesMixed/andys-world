## Maps to

Regular Week 3 — a consolidation lesson covering all four Structures sub-topics: types & rigidity; forces & structural members; loads, moments & Factor of Safety; joining & reinforcing. Students already have this foundation from prior teaching — the regular class consolidates; SKILLS goes engineering-deep across all four as one connected problem.

Because SKILLS starts this term at W3, this is also the first SKILLS session the 18 attend, and several have not yet settled on a specific project — generic ideas, no real user, or just indecision. The structures analysis below is run on *their own* project rather than a generic example, so committing to it is not optional.

## Preview

*Lock the brief first* (see run sheet): one line, forced — "For [a named user], to [a specific need], carrying [a real load]." No user or load stated means it isn't decided yet. Then a rapid end-to-end tour: structure type → what forces it carries → stress and FoS in a key member → how to join it. The engineering chain.

## Deepen

Connecting the four areas: truss classification and triangulation; identifying ties and struts by inspection; full stress and FoS calculation (σ = F/A; moments); joint selection with anti-movement detail (gussets, corner blocks, KD fittings); why each choice follows from the force analysis.

## Taste beyond

The method of sections (cutting a truss to find member forces algebraically); shear-force and bending-moment diagrams as a concept; real structural engineering — how a bridge or mezzanine uses all four areas together.

## TA prep

*Breadth is the challenge.* You may be called on for any of the four sub-topics in the regular class. Prepare a mental map: "If a peer is stuck on … I ask …" Common error: treating structures as four isolated vocabulary lists. Tutoring cue: *"If you know the structure type, what forces must it carry — and where is the stress highest?"*

A second, quieter cue for this week: several peers in the regular class will also still be undecided on their project — if one is stuck, ask *"Who is it for, and what's the heaviest thing it has to hold?"* rather than suggesting a product.

## Challenge

Run the full structures problem on *your own project*, not a generic truss: (1) classify its main structure and identify members as tie or strut; (2) find the reactions and calculate stress in the heaviest-loaded member; (3) design and justify a joint for the most critical connection. If the project is too vague to do this, that is the signal to fix the brief before next week.

## Run sheet

0–8 lock the one-line brief (user + need + load) — no exceptions; 8–15 rapid engineering-chain tour; 15–30 deep across all four connected, applied live to each student's own structure; 30–37 advanced analysis taste; 37–45 TA breadth prep + challenge.

## Take-away

Write a one-page flow chart: structure type → forces → calculations → joints — for your own project. If your one-line brief still isn't locked, that is this week's priority before SK2.
