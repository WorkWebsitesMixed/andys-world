<WeekLink grade={12} term={1} week={9}>This week's main session</WeekLink> adds four packages to the Chemistry report — `mhchem`, `graphicx`, `booktabs`, `biblatex`. Your report doesn't need chemical equations, so this session covers three of the four: the ones that make almost any structured document look professional and stay consistent.

<Callout type="tip" title="Why this matters" id="why">
  A table typed with spaces and dashes looks fine until you edit one row and the columns stop lining up. A citation typed as `[1]` by hand looks fine until you insert a new source in the middle and have to renumber every one that follows by hand. `booktabs` and `biblatex` exist because both of those problems are common, and both are entirely avoidable.
</Callout>

<Section title="Three packages, one report" icon="📊" id="topic">

### Tables with booktabs

```latex
\usepackage{booktabs}

\begin{table}[h]
\centering
\caption{Comparison of three regional solar projects}
\label{tab:solar}
\begin{tabular}{lcc}
\toprule
Project & Capacity (MW) & Cost per MW (USD) \\
\midrule
Project A & 40 & 1.2M \\
Project B & 25 & 1.5M \\
Project C & 60 & 1.0M \\
\bottomrule
\end{tabular}
\end{table}
```

Only `\toprule`, `\midrule` and `\bottomrule` — no vertical lines, no boxed grid. That's a deliberate typographic convention, not a limitation: publication tables avoid vertical rules because they add clutter without adding information.

### Figures with graphicx

```latex
\usepackage{graphicx}

\begin{figure}[h]
\centering
\includegraphics[width=0.7\textwidth]{project-photo.jpg}
\caption{Prototype chassis, side view}
\label{fig:chassis}
\end{figure}
```

Refer to it in your text with `Figure~\ref{fig:chassis}` — not "the figure below." If you add a second figure before this one later, `\ref{}` updates the number automatically. A hand-typed "Figure 1" doesn't.

### Citations with biblatex

Add to the preamble:

```latex
\usepackage[style=numeric, sorting=none]{biblatex}
\addbibresource{refs.bib}
```

Create a `refs.bib` file (New File in Overleaf) with one entry per source:

```
@online{iea2023,
  author = {International Energy Agency},
  title = {Renewables 2023},
  year = {2023},
  url = {https://www.iea.org/reports/renewables-2023}
}
```

Cite it in text with `\cite{iea2023}`, and add `\printbibliography` before `\end{document}` to generate the full reference list.

</Section>

<WorkedExample title="Plain-text table → booktabs table">
Weak: a paragraph reading *"Project A has 40 MW capacity and costs 1.2M per MW, Project B has 25 MW and costs 1.5M per MW..."*

Improved: the three-row `booktabs` table above — same data, instantly scannable, and referenced from the text as `Table~\ref{tab:solar}` instead of "the numbers above."

The improvement isn't just visual. A reader (or examiner, or reviewer) can compare three numbers across a row in half a second in table form; the same comparison buried in a sentence takes real effort to extract.
</WorkedExample>

<Activity title="Add a table and a citation" time="25 min" grouping="Individual" materials={["Laptop", "Overleaf — your report project from B8", "At least one real source for your topic"]}>
1. Add `\usepackage{booktabs}` to your preamble. Build one table relevant to your topic — even 3 rows of made-up placeholder data is fine for now.
2. Add `\usepackage[style=numeric, sorting=none]{biblatex}` and `\addbibresource{refs.bib}` to your preamble.
3. Create `refs.bib` and add one real source about your topic.
4. Cite it in your Introduction with `\cite{}`, and add `\printbibliography` at the end of the document.
5. Compile. If the citation shows as `[?]`, you're missing `\printbibliography` or need to compile twice (Overleaf sometimes needs a second pass to resolve references).
</Activity>

<Support title="Mark scheme — troubleshooting checklist">
- **Citation shows `[?]` instead of a number** → check you added `\printbibliography`, and try compiling a second time.
- **"File 'refs.bib' not found"** → check the filename matches exactly, including the `.bib` extension, in both the file itself and `\addbibresource{}`.
- **Table columns misaligned** → count your `&` symbols — one fewer than the number of columns per row, and every row must have the same count.
- **Figure doesn't appear** → check the image file was uploaded to the Overleaf project, and the filename in `\includegraphics{}` matches exactly.
</Support>
