<Section title="Building today's topic" icon="💬" id="topic">

### What could go wrong with a company's data?

Build the list, then sort it into three categories, because the category is what the exam actually tests:

- **Malicious external** — hacking, phishing, a virus sent from outside.
- **Malicious internal** — an employee deliberately misusing access they legitimately have.
- **Accidental** — deletion by mistake, hardware failure, fire or flood.

The same event can sit in different categories depending on intent — a deleted file is accidental; the same file deleted deliberately by an angry ex-employee is malicious internal. The exam wants you to reason about intent, not just name the threat.

### Countermeasures — logical

**Encryption** doesn't just "keep data safe" — it *scrambles* data using an algorithm, so that only someone holding the correct key can decode it back into something readable. That's why encrypted data intercepted in transit is still useless to whoever intercepted it. Passwords, two-factor authentication, antivirus software, firewalls, and access levels (different users see different data) all work alongside encryption as separate layers, not substitutes for it.

### Countermeasures — physical

Lock and key, security passes, CCTV, biometric entry, cable locks — physical measures protect the hardware itself, which logical measures like encryption can't do on their own. A stolen unencrypted laptop is a data breach regardless of how good the firewall was.

### Backups — why off-site, and what's the difference between full and incremental?

*"Why is a backup stored off-site?"* Because a backup stored in the same building as the original is destroyed by the same fire, flood, or theft that destroys the original — it isn't really a backup at all if it shares the same risk. A **full backup** copies everything, every time — simple to restore from, but slow to create. An **incremental backup** copies only what's changed since the last backup — fast to create, but restoring means reassembling the full backup plus every incremental since, in order.

### Phishing vs hacking

*"How is phishing different from hacking?"* Hacking exploits a technical vulnerability in a system. Phishing exploits a human one — it deceives the user into voluntarily handing over their own credentials, no technical break-in required.

<WorkedExample title="Weak answer → improved answer (encryption)">
**Question:** "Explain how encryption protects data that is intercepted during transmission."

Weak: *"Encryption keeps data safe."*

Improved: *"Encryption converts data into a coded format using an algorithm, so that only someone with the correct decryption key can turn it back into readable data. If the data is intercepted during transmission, the attacker only has the scrambled version and cannot understand it without the key."*

The improvement earns marks by explaining the **mechanism** — data is converted using an algorithm — and by linking that mechanism directly to **why it stops the specific threat** described in the question (interception).
</WorkedExample>

Attempt all three before checking the mark scheme below.

1. A school employee accidentally deletes the entire student record folder. Which threat category does this belong to, and why?
2. A company backs up its server every night, keeping only the changes since the previous night's backup. What type of backup strategy is this, and what's the main disadvantage if a restore is needed?
3. Explain, with a reason, why a fingerprint scanner at a server room door is a physical rather than a logical security measure.
</Activity>

<Support title="Mark scheme — check your answers">
1. **Accidental** — there was no intent to cause harm; the deletion happened by mistake, which is what defines this category regardless of how serious the consequence is.
2. This is an **incremental backup strategy**. The main disadvantage is that restoring requires the last full backup *plus every incremental backup since*, applied in the correct order — more steps, and a longer restore process than a full backup would need.
3. It's **physical** because it controls who can physically enter a location (the server room) — it protects the hardware itself, not the data through software or algorithms, which is what makes something a logical measure instead.
</Support>
