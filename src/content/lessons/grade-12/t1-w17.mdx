<Section title="Building today's topic" icon="💬" id="topic">

### The systems life cycle — what if you were building a new school database?

Six stages, in order: **Analysis** (what does the school actually need?) → **Design** (plan the structure) → **Development** (build it) → **Testing** (does it work?) → **Implementation** (put it into real use) → **Evaluation** (did it succeed?). The key exam question is: *"What happens in Testing that can't happen in Development?"* Testing uses real or realistic data under real conditions — and when it finds errors, the process loops back to Development. That loop-back is what makes SDLC iterative, not a straight line.

### Software types — the distinction that's easy to get wrong

An **operating system** manages the hardware itself, provides the interface you interact with, and manages files — Windows, macOS, the layer everything else runs on top of. **Application software** does one specific job for the user — a word processor, a spreadsheet, a browser. **Utility software** doesn't do a user's task at all; it maintains the system — antivirus scanning for threats, a defragmenter reorganising a disk, a compression tool shrinking file sizes. The exam trap almost writes itself: *"Microsoft Word is an operating system."* It isn't — it's application software, because it performs one specific task (document editing) rather than managing the hardware.

### Health and ergonomics — what can long-term computer use actually cause?

Three physical problems, each with a specific cause and a specific fix, not a vague "take breaks":

- **RSI** (repetitive strain injury) — caused by repeated keyboard/mouse motion; countered with a wrist rest and correct hand position.
- **Eye strain** — caused by screen glare or incorrect viewing distance; countered with an anti-glare screen and regular breaks (the 20-20-20 rule: every 20 minutes, look at something 20 feet away for 20 seconds).
- **Back/neck pain** — caused by poor posture; countered with an adjustable chair and correct monitor height, level with the eyes.

</Section>

<WorkedExample title="Weak answer → improved answer (software types)">
**Question:** "State the type of software Microsoft Word is, and explain why."

Weak: *"Microsoft Word is an operating system because it's very important software."*

Improved: *"Microsoft Word is application software, because it performs one specific task — creating and editing documents — for the user. An operating system, by contrast, manages the computer's hardware and provides the environment in which applications like Word run."*

The improvement earns marks by giving the **correct category**, then explaining the **defining feature of that category** (a specific user task) and contrasting it precisely with what an operating system actually does.
</WorkedExample>

<Activity title="Short-answer practice" time="17 min" grouping="Individual" materials={["Paper or notebook"]}>
Attempt all three before checking the mark scheme below.

1. A school is building a new library catalogue system. Testing reveals the search function returns incorrect results. Which SDLC stage does the team return to, and why can't this problem simply be fixed during Implementation?
2. State the type of software antivirus is, and explain why it doesn't fit either of the other two categories.
3. A student develops wrist pain after months of daily laptop use for schoolwork. Name the condition and one specific countermeasure.
</Activity>

<Support title="Mark scheme — check your answers">
1. The team returns to **Development** — Testing found a functional error (incorrect search results), and fixing the underlying logic is a development task, not an implementation one. Implementation is about putting a *working* system into real use; you can't implement a system that doesn't work correctly yet.
2. Antivirus is **utility software** — it doesn't perform a specific user task (ruling out application software) and it doesn't manage hardware or provide the user interface (ruling out operating system); its job is system maintenance, scanning for and removing threats.
3. **RSI (repetitive strain injury)**. Countermeasure: a wrist rest to support correct hand position and reduce strain during typing (a break schedule or an ergonomic mouse are also acceptable).
</Support>
