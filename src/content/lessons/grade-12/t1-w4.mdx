Paper 2 opens with document production in Microsoft Word. The marks test whether you followed the exact sequence — applying a named style is not the same as changing the font to look similar, and the mark scheme checks exactly what's specified, not what merely looks right. Today you practise each task until the process is reliable.

<Callout type="exam" title="Why this matters" id="why">
  **Paper 2** (2.5 hours) covers document production (Word), databases (Access) and presentations (PowerPoint). Document production accounts for the first section. The most common losses are: applying a font change instead of a named style, omitting field codes from headers/footers, and choosing the wrong image text-wrap setting. All three are drilled today.
</Callout>

<KeyTerms terms={[
  { term: "Named style", definition: "A saved set of formatting (font, size, spacing, colour) given a name, e.g. 'Heading 1'. Applying the named style — not just making the text look similar — is what earns the mark." },
  { term: "Field code", definition: "An instruction in a header or footer that inserts live data — e.g. the current filename or date — instead of fixed typed text." },
  { term: "Text wrapping", definition: "How body text flows around an image. The question specifies exactly which wrap type to apply — choosing the wrong one loses the mark." },
]} />

<Section title="Practical: Microsoft Word tasks" icon="💻" id="practical">

### Task 1 — Named styles (most-lost marks)

Home → Styles panel → click the exact style name specified in the question.

**The critical rule:** applying the named style from the Styles panel earns the mark. Changing the font manually to *look* like the style does not — even if the result is visually identical. The mark scheme checks whether the style is applied, not whether it looks right.

To verify: click inside the formatted text → check the Styles panel highlights the correct style name.

### Task 2 — Headers and footers with field codes

Insert → Header (or Footer) → Edit Header, then insert field codes as specified:

| What the question wants | How to insert it |
|---|---|
| Automatic filename | Insert → Quick Parts → Field → choose `FileName` |
| Page number | Insert → Page Number → choose position |
| Date (automatic) | Insert → Quick Parts → Field → choose `Date` |

After inserting: right-click the field → Update Field to confirm it shows correct data. Close Header and Footer when done.

### Task 3 — Image text wrapping

Click the image → Picture Tools Format → Wrap Text → choose the wrap type named in the question (Square, Through, In Line with Text, Top and Bottom, etc.).

The question always specifies the wrap type. Choosing the wrong one loses the mark even if the image is positioned correctly.

<WorkedExample title="Typed date vs field code: tracing a common failure">
Scenario: the question asks for a footer showing "today's date, updated automatically." A student types `10/08/2026` directly into the footer. It displays correctly today.

**Why it fails:** typed text is not a field code — it never changes and it isn't what the mark scheme is checking for. Right-click the text → Toggle Field Codes would show plain characters, not `{ DATE }`. A visually correct date on marking day earns nothing if it isn't actually a field.

**Fix:** delete the typed text. Insert → Quick Parts → Field → choose `Date`, tick "Update automatically", OK. Right-click → Update Field to confirm it refreshes to the current date.
</WorkedExample>
