<Section title="Why bother? LaTeX against Word and Google Docs" icon="💡" id="why-latex" step="1–2">

### Where LaTeX is used

LaTeX is how most scientific and mathematical writing is produced. Journals and conferences in mathematics, physics, computer science and engineering publish LaTeX templates for authors. Many university theses and dissertations are written in it. Textbooks with a lot of equations are often typeset with it. Preprint servers such as arXiv accept LaTeX source files. When you write a lab report in LaTeX you are using the same tool a researcher uses to write a paper, with the same file format.

### What it does for you that a word processor does not

| What you need | In Word or Google Docs | In LaTeX |
|---|---|---|
| A chemical formula or an equation | Insert a special object, or type `H2O` and format each digit by hand | `\ce{H2O}` or `$E = mc^2$`: the same command everywhere, always typeset correctly |
| Figure and table numbers | Numbered by hand, or by a feature you have to remember to update | Numbered automatically; `\ref{}` updates every mention when you reorder |
| Reference list | Typed by hand, or by a plug-in | Built from one `.bib` file; the style is changed in one line |
| A long document | Layout drifts as you edit; headings and the table of contents need care | Headings, contents and numbering are generated from the structure |
| Changing the layout or the template | Restyle by hand, often breaking something | Change one line or load a different template |
| What is stored | A binary file that only the right program opens faithfully | Plain text: any computer opens it, and version control tools can show exactly what changed |
| Cost | Word is paid; Google Docs is free but online | Free |

The idea behind all of this is that **you describe the structure and LaTeX does the layout**. In a word processor you are both author and typesetter at the same time. Separating those jobs is what makes long, technical documents stay consistent.

### The honest version: when Word or Docs is the better choice

<Callout type="info" title="Use the right tool" id="when-not">
LaTeX has a learning curve, and you do not see the page as you type. For a quick letter, an invitation, a poster or anything where the visual layout is the point, Word, Docs or a design tool is faster. Google Docs is also much better when several people are commenting and suggesting changes at once. Choose LaTeX when the document is long, technical, full of equations, figures or citations, or when it has to stay correct while it changes.
</Callout>

### What this means for you

You will write the Chemistry lab report in LaTeX over the next weeks. The skills carry on: if you study science, engineering or mathematics, the reports and papers you write at university are very likely to use it, and you will already know the commands. If you do something else, you will still have learned to separate content from layout, which is useful in any tool.

</Section>

<Section title="LaTeX document structure" icon="💻" id="lesson" step="3">

### The skeleton every document starts with

```latex
\documentclass[12pt]{article}
\usepackage{geometry}
\usepackage[utf8]{inputenc}

\begin{document}

Your content goes here.

\end{document}
```

Everything before `\begin{document}` is the **preamble**. Everything between `\begin{document}` and `\end{document}` is the **body**.

### Key commands

| Command | What it does |
|---|---|
| `\section{Title}` | Creates a numbered section heading |
| `\subsection{Title}` | Creates a numbered sub-heading |
| `\textbf{text}` | **Bold** text |
| `\textit{text}` | *Italic* text |
| `\emph{text}` | Emphasis — usually italic, context-aware |
| Blank line | Starts a new paragraph |
| `%` | Comment — LaTeX ignores everything after this on the line |

### Packages: adding extra features

Packages extend what LaTeX can do. Load them in the preamble with `\usepackage{name}`.

```latex
\usepackage{geometry}          % controls page margins
\usepackage[utf8]{inputenc}    % handles accented characters (á, é, etc.)
```

### Reading a compile error

When the PDF doesn't build, Overleaf shows a red error panel. Click it to see the log. The key information is:

- **Line number** — go to that line in the editor.
- **Error message** — common ones: "Missing } inserted" (unclosed brace), "Undefined control sequence" (typo in command name).

**Rule:** every `{` needs a matching `}`. Every `\begin{env}` needs a matching `\end{env}`.

### Common first-session mistakes

| Mistake | What to check |
|---|---|
| `/section` instead of `\section` | Backslash `\`, not forward slash `/` |
| Edited PDF pane | Source pane is on the left — that's where you type |
| Changed something but PDF didn't update | Did you click **Recompile**? |
| Wrong quotation marks | Use ` `` ` for opening, `''` for closing — not `"text"` |

</Section>

<WorkedExample title="Writing the Introduction section" step="4">
Your teacher shares an Overleaf project link. Open it. The preamble is already set. You need to write the Introduction section of the Chemistry lab report.

In the body, add:

```latex
\section{Introduction}

This experiment investigates the thermal decomposition of potassium chlorate.
Potassium chlorate (\ce{KClO3}) decomposes when heated to produce oxygen gas
and potassium chloride.

The aim of this experiment is to observe the reaction and collect the oxygen
produced.
```

The `\ce{}` command for the formula comes from the `mhchem` package — that's Week 9. For now, write the formula as plain text with a note to fix it next week.

Click **Compile** (Ctrl+Enter). Check the PDF. Fix any errors shown in the log.
</WorkedExample>
<Support title="LaTeX first-session survival guide" id="survival" step="4">
If the PDF won't compile:

1. Click the error panel in Overleaf.
2. Find the line number in the error message.
3. Go to that line in the source.
4. Look for: unclosed `{`, missing `}`, typo in a command name (`\scetion` instead of `\section`).
5. Fix it. Compile again.

Don't delete sections and restart — that makes it harder to find the error.
</Support>
